# Cash Check

Офлайн-приложение для учёта личных трат. Крупный баланс по центру,
траты списываются с него снизу. Никакой сети, никаких аккаунтов —
все данные лежат в локальной SQLite на устройстве.

## Как устроено

- **Баланс** — просто сумма в кошельке. Тап по числу → правка вручную.
- **Трата** — сумма + название. Списывается с баланса в одной транзакции БД,
  поэтому баланс и список не могут разъехаться.
- **Свайп влево** по трате — удалить. Сумма возвращается на баланс.
- **История** — все операции, сгруппированные по дням с итогом за день.

## Стек

| Что | Чем |
|---|---|
| UI | Flutter (Material 3, тёмная тема) |
| Состояние | `provider` + `ChangeNotifier` |
| Хранилище | `sqflite` (локальный SQLite) |
| Сборка | Codemagic → release APK |

## Структура

```
lib/
├── main.dart              точка входа, инициализация БД
├── theme/app_theme.dart   палитра и тема
├── utils/money.dart       форматирование и парсинг сумм
├── data/                  модели + репозиторий (SQLite)
├── state/                 WalletState — единый источник правды для UI
├── screens/               главный экран и история
└── widgets/               баланс, плитка траты, шит ввода суммы
```

## Локальный запуск

```bash
flutter pub get
flutter create --platforms=android .   # только при первом клоне
flutter run
```

## Сборка APK

Codemagic подхватывает `codemagic.yaml` автоматически.
Платформенные файлы Android генерируются на лету, поэтому в репозитории
их нет — так gradle-конфиг всегда совпадает с версией Flutter на билд-машине.

## Валюта
